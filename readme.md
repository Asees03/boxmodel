# Task 3: CSS Units, Box Models, Fonts

## Description
This task demonstrates CSS viewport units, the box model,
image styling, and button customization using a gradient background.

## Files
- index.html: Contains the webpage structure.
- style.css: Contains the styling rules.

## Features
- Responsive image container using viewport units.
- Image displayed inside a div.
- Gradient button with customized font settings.
- Universal box-sizing: border-box.
- No Flexbox, overflow: hidden, or relative/absolute positioning.

## How to Run
1. Keep index.html and style.css in the same directory.
2. Open index.html in a web browser.
3. Ensure you have an internet connection to load the image.

## Technologies
- HTML5
- CSS3
